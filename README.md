# Praktikum Informatik 2 – Traffic Simulation

This project was developed as part of the course **Praktikum Informatik 2** at RWTH Aachen. The goal of the project was to implement an object-oriented traffic simulation in **C++**. 

## Project Description

The project simulates a simplified traffic system in which vehicles such as **cars** and **bicycles** move along roads between intersections. Various object-oriented programming concepts were applied throughout the implementation. 

## Concepts Used

* Object-oriented programming in C++
* Inheritance and polymorphism
* Smart pointers (`unique_ptr`, `shared_ptr`)
* STL containers (`vector`, `list`, `map`)
* Exception handling
* Templates
* Operator overloading
* Vehicle and road simulation

## Project Features

The project includes several functional components:

* Implementation of vehicle classes
* Simulation of cars and bicycles
* Management of roads and intersections
* Traffic and route simulation
* Graphical visualization of the simulation
* Usage of STL and modern C++ concepts
